Act 1 — the problem

Modulo hashing: one dead server, chaos everywhere

Each key is placed by dividing its hash by the number of servers and keeping the remainder. Simple and fast — until the number of servers changes.

serverIndex = hash(key) % 4

These are the same 8 keys and the same hash values as Table 5-1 in the chapter.

Act 2 — the fix

The hash ring

Two changes fix everything. First, throw away the % N — now no part of the maths knows how many servers exist, so nothing breaks when that number changes. Second, hash the servers onto the same circle as the keys. Then a single rule places every key: start at the key and walk clockwise; the first server you meet owns it.

Act 3 — the refinement

Why virtual nodes are not optional

The four servers above happen to sit tidily around the circle. Real hashing is rarely that kind. With one point per server the arcs are random, so one machine can easily end up owning half the ring — and when it dies, that whole half lands on a single neighbour. Give each server many points instead and it owns many small arcs, which average out.

Each row is averaged over 24 differently-named clusters, because a standard deviation taken across only a handful of servers is far too noisy to read a trend from. The numbers track 1/√V closely, which is why the chapter quotes roughly 10% at 100 virtual nodes and 5% at 200. Cost of the trick: 4 servers with 200 virtual nodes means 800 points to store and search instead of 4. A bigger routing table buys a fairer spread.

Recap

The whole chapter in five lines

  1. Modulo hashing spreads keys evenly but cannot survive a change in N, because the divisor is baked into every answer.
  2. Put the hash space on a circle and hash servers onto it as well as keys.
  3. A key belongs to the first server clockwise of it. That is the entire lookup.
  4. Adding or removing a server only rewrites one arc, so only that arc's keys move — about k/n of them, instead of nearly all.
  5. Give every server many virtual nodes so the arcs are numerous and small, which makes the load fair and stops one death from crushing one neighbour.
